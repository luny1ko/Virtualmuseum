Как закинуть картинки внутрь программы

1. Замени файлы из этого архива в проекте.
2. Открой терминал в папке PP/static/assets.
3. Выполни команду:
   python download_images.py

После этого все картинки с внешних ссылок сохранятся в PP/static/assets, а программа будет брать их изнутри проекта.

Я уже заменил ссылки в HTML/CSS/JS на локальные пути вида /static/assets/имя_файла.
